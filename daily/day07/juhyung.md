# 7일차 작업일지 - 안주형

## 오늘 진행한 작업

### 1. 전체 애플리케이션 실행 테스트

FastAPI 서버와 MySQL 데이터베이스를 실행하고 프론트엔드에서 주요 기능을 직접 테스트하였다.

### 2. 로그인 및 회원 관리 테스트

- 관리자 계정 로그인 확인
- 로그인 사용자 정보 조회 확인
- 관리자 회원 목록 조회 확인

### 3. 환자 관리 기능 테스트

- 환자 목록 조회
- 신규 환자 등록
- 환자 상세 정보 조회

테스트 환자를 직접 등록하여 환자 관련 API와 프론트엔드가 정상적으로 연결되는지 확인하였다.

### 4. 진료기록 및 X-Ray 테스트

- 환자 진료기록 등록
- 진료기록 상세 조회
- X-Ray 이미지 업로드
- 업로드한 X-Ray 이미지 화면 출력 확인

### 5. AI 폐렴 예측 테스트

등록한 X-Ray 이미지를 이용하여 AI 폐렴 예측을 실행하였다.

예측 결과 화면에서 다음 정보가 정상적으로 표시되는 것을 확인하였다.

- 폐렴 여부
- Confidence
- 사용 AI 모델 `PneumoniaModel-v1`

### 6. 실행 화면 문서 작성

앱의 주요 기능별 실행 화면을 캡처하고 다음 문서를 작성하였다.

`docs/7일차_앱_실행화면.md`

실행 화면 이미지는 `docs/day07_images/`에 정리하였다.

## 작업 중 발생한 문제

- 재부팅 후 로컬 MySQL과 Docker MySQL 실행 상태로 인해 데이터베이스 연결 문제 발생
- AI 예측 실행 과정에서 PyTorch DLL 관련 오류 발생
- Microsoft Visual C++ Redistributable 설치 및 실행 환경 확인 후 AI 모델 정상 실행 확인

## 최종 결과

다음 기능의 정상 동작을 확인하였다.

- 관리자 로그인
- 회원 관리
- 환자 등록 및 조회
- 진료기록 등록 및 조회
- X-Ray 이미지 업로드 및 출력
- AI 폐렴 예측 실행
- AI 예측 결과 조회

프론트엔드와 FastAPI API의 연결 및 AI 예측 기능까지 전체 실행 테스트를 완료하였다.
