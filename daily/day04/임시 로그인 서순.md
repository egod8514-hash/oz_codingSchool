# 🛠️ [공통 가이드] 임시 인증(`X-User-Id`) 및 Swagger UI 테스트 가이드

JWT 기반 인증 시스템 구현 전까지 각자 담당한 API(마이페이지, 관리자 기능 등)를 독립적으로 개발하고 테스트할 수 있도록 **임시 인증 의존성(`dependencies.py`)**을 제공합니다.

본 가이드를 참고하여 로컬 DB에 테스트 데이터를 세팅하고, 본인 API 라우터에 의존성을 연결해 Swagger UI에서 테스트를 진행해 주세요.

## 2. 로컬 MySQL 테스트 계정 생성 (SQL 실행)

로그인/회원가입 API 완료 여부와 관계없이 권한별 테스트(스태프, 어드민, 대기자)가 가능하도록, VS Code의 SQL 에디터 또는 DB 클라이언트(DBeaver 등)에서 아래 쿼리를 실행합니다.

```sql
-- 1. 어드민 계정 (관리자 전용 기능 테스트용)
INSERT INTO users (email, password, name, department, gender, phone, role, is_active, is_deleted, created_at)
VALUES ('admin@hospital.com', 'dummy_hash', '관리자', '개발', 'M', '010-0000-0001', '어드민', true, false, NOW());

-- 2. 일반 스태프 계정 (마이페이지 조회, 정보 수정, 비번 변경 테스트용)
INSERT INTO users (email, password, name, department, gender, phone, role, is_active, is_deleted, created_at)
VALUES ('doctor@hospital.com', 'dummy_hash', '김의사', '의료', 'F', '010-1234-5678', '스태프', true, false, NOW());

-- 3. 대기자 계정 (권한 변경 대상자 테스트용)
INSERT INTO users (email, password, name, department, gender, phone, role, is_active, is_deleted, created_at)
VALUES ('pending@hospital.com', 'dummy_hash', '박대기', '연구', 'M', '010-9999-8888', '대기자', true, false, NOW());
```

> **확인 쿼리:** `SELECT id, email, name, role FROM users;`  
> 생성된 계정의 `id` 번호(보통 `1`, `2`, `3`)를 기억해 둡니다.

## 3. 공통 의존성 확인 시 주의사항 (`dependencies.py`)

> ⚠️ **주의:** SQLAlchemy의 `select(User)` 쿼리에는 Pydantic 스키마가 아닌 **SQLAlchemy ORM 모델(`app.models.user`)**을 임포트해야 합니다.

```python
# app/core/dependencies.py
from fastapi import Header, HTTPException, Depends, status
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select

from app.core.db.databases import async_get_db
from app.models.user import User  # 반드시 app.schemas가 아닌 app.models에서 import

async def get_current_user(
    x_user_id: int = Header(..., alias="X-User-Id", description="로그인한 유저 ID (1=어드민, 2=스태프, 3=대기자)"),
    db: AsyncSession = Depends(async_get_db)
) -> User:
    stmt = select(User).where(User.id == x_user_id)
    result = await db.execute(stmt)
    user = result.scalar_one_or_none()

    if not user:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND, 
            detail="해당 ID의 유저를 찾을 수 없습니다."
        )
    if getattr(user, "is_deleted", False):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED, 
            detail="탈퇴 처리된 계정입니다."
        )
    return user

async def require_admin(current_user: User = Depends(get_current_user)) -> User:
    if current_user.role != "어드민":
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN, 
            detail="관리자(어드민) 권한이 필요합니다."
        )
    return current_user
```

## 4. 본인 담당 라우터에 의존성(`Depends`) 적용

작성 중인 API 함수의 매개변수에 `get_current_user` 또는 `require_admin`을 주입하면, **Swagger UI에 자동으로 `x-user-id` 헤더 입력창이 노출**됩니다.

### (1) 일반 로그인 유저 API (내 정보 조회, 프로필 수정, 탈퇴 등)

로그인한 사용자 본인의 정보 조회가 필요한 API는 `Depends(get_current_user)`를 연결합니다.

```python
# app/apis/본인_라우터_파일명.py
from fastapi import APIRouter, Depends
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.dependencies import get_current_user
from app.core.db.databases import async_get_db
from app.models.user import User
from app.schemas.user import UserUpdateRequest  # 본인 DTO 스키마

router = APIRouter(prefix="/api/v1/users", tags=["Users"])

@router.patch("/me")
async def update_my_profile(
    body: UserUpdateRequest,
    current_user: User = Depends(get_current_user),  # <-- 임시 인증 주입 (Swagger 헤더 자동 생성)
    db: AsyncSession = Depends(async_get_db)
):
    # current_user.id, current_user.email 등 DB에서 조회된 ORM 객체 바로 사용 가능
    return {
        "status": "success",
        "user_id": current_user.id,
        "message": f"{current_user.name}님의 정보 수정 완료"
    }
```

### (2) 관리자 전용 API (권한 변경, 전체 유저 관리 등)

관리자(`role == '어드민'`) 권한 체크가 필요한 API는 `Depends(require_admin)`을 연결합니다. 일반 유저 ID가 전달되면 자동으로 `403 Forbidden` 에러를 반환합니다.

```python
from app.core.dependencies import require_admin

@router.patch("/admin/users/{target_user_id}/role")
async def change_user_role(
    target_user_id: int,
    admin: User = Depends(require_admin),  # <-- 관리자 권한 자동 검증
    db: AsyncSession = Depends(async_get_db)
):
    return {
        "status": "success",
        "admin_name": admin.name,
        "target_user_id": target_user_id
    }
```

## 5. Swagger UI(`/docs`)에서 테스트 절차

1. **서버 구동:**
   ```bash
   fastapi dev main.py
   ```
2. **문서 접속:**  
   브라우저에서 `http://127.0.0.1:8000/docs` 접속
3. **API 엔드포인트 선택:**  
   테스트할 API 클릭 $\rightarrow$ 우측 상단 **[Try it out]** 클릭
4. **헤더 값 입력:**  
   **Parameters** 영역에 노출된 **`x-user-id`** 입력 필드에 테스트할 유저 ID 입력
   * **일반 스태프로 테스트 시:** `2` 입력
   * **관리자로 테스트 시:** `1` 입력
   * **없는 계정 에러 검증 시:** `999` 입력 (`404 Not Found` 확인)
   * **관리자 API에 스태프(`2`) 입력 시:** `403 Forbidden` 차단 확인
5. **실행:**  
   Request Body 작성 후 파란색 **[Execute]** 버튼 클릭
6. **결과 확인:**  
   하단 Responses에서 HTTP 상태 코드(`200`, `403`, `404`) 및 JSON 응답 데이터 확인

## 6. 프론트엔드(Vanilla JS `fetch`) 연동 규격

HTML/JS 화면에서 비동기 호출을 보낼 때는 `headers` 객체에 `X-User-Id`를 추가하여 전송합니다.

```javascript
// 현재 로그인된 유저 ID가 2번(김의사)인 경우
const currentUserId = 2;

fetch("[http://127.0.0.1:8000/api/v1/users/me](http://127.0.0.1:8000/api/v1/users/me)", {
  method: "PATCH",
  headers: {
    "Content-Type": "application/json",
    "X-User-Id": currentUserId // 임시 인증 헤더
  },
  body: JSON.stringify({
    department: "원무과",
    phone: "010-1234-5678"
  })
})
  .then(res => {
    if (!res.ok) throw new Error(`HTTP Error: ${res.status}`);
    return res.json();
  })
  .then(data => console.log("응답 성공:", data))
  .catch(err => console.error("오류 발생:", err));
```

## 7. 트러블슈팅 FAQ

* **Q. `ArgumentError: Column expression, FROM clause ... got <class 'app.schemas.user.User'>` 에러가 납니다.**
  * `dependencies.py` 상단에서 `from app.schemas.user import User`로 잘못 가져왔을 때 발생합니다. `from app.models.user import User`로 변경해 주세요.
* **Q. Swagger UI에 `x-user-id` 입력창이 보이지 않습니다.**
  * 라우터 함수의 파라미터에 `current_user: User = Depends(get_current_user)`가 누락되어 있지 않은지 확인해 주세요.
* **Q. `404 Not Found: 해당 ID의 유저를 찾을 수 없습니다.` 에러가 납니다.**
  * 로컬 DB `users` 테이블에 2번 항목의 INSERT SQL을 실행했는지 확인하고, DB에 실제 생성된 `id` 번호와 입력한 번호가 일치하는지 확인해 주세요.
* **Q. 나중에 JWT 토큰 인증으로 변경할 때 라우터 코드를 전부 수정해야 하나요?**
  * 아닙니다. 추후 `app/core/dependencies.py` 내부의 `get_current_user` 함수만 `Header(...)` 대신 `OAuth2PasswordBearer` 및 JWT 검증 로직으로 교체하면, 각자 작성한 라우터 코드는 한 줄도 수정할 필요 없이 그대로 유지됩니다.
