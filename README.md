# AI Health Web Assignment

AI 기반 헬스케어 웹 서비스를 제작하기 위한 팀 프로젝트입니다.

팀원들과 역할을 분담하고 Git/GitHub를 활용하여 협업하였으며, FastAPI를 기반으로 사용자 관리, 환자 관리, 진료 기록 관리 및 AI 폐렴 예측 기능을 구현하였습니다.

---

# 프로젝트 진행 과정

## 1. Team Rule 정의

프로젝트 시작 전 원활한 협업을 위해 팀 규칙을 정하였습니다.

- 팀 코어타임을 정하고 해당 시간에 프로젝트 진행
- 참석이 어려운 경우 팀원들에게 미리 공유
- 매일 작업할 내용과 진행 상황 공유
- 작업 중 발생한 문제나 막힌 부분 공유
- Git/GitHub를 활용하여 작업 내용 관리
- 팀원 간 원활한 소통을 위한 협업 규칙 설정

---

## 2. 사용자 요구사항 정의

AI 헬스케어 웹 서비스에 필요한 기능을 확인하고 구현할 주요 기능을 정리하였습니다.

주요 기능은 다음과 같습니다.

- 사용자 로그인 및 인증
- 회원 관리
- 환자 등록 및 조회
- 환자 상세 정보 관리
- 진료 기록 등록 및 조회
- X-Ray 이미지 등록
- AI 폐렴 예측
- AI 예측 결과 조회

이를 바탕으로 필요한 API와 화면 기능을 정리하였습니다.

---

## 3. API 명세 작성

프론트엔드와 백엔드가 통신하기 위해 필요한 API를 정의하였습니다.

기능에 따라 HTTP Method를 구분하여 API를 구성하였습니다.

```text
GET     → 데이터 조회
POST    → 데이터 생성
PUT     → 데이터 수정
PATCH   → 데이터 일부 수정
DELETE  → 데이터 삭제
```

프로젝트에서는 다음 기능을 API로 구성하였습니다.

- 사용자 인증 API
- 회원 관리 API
- 환자 관리 API
- 진료 기록 API
- X-Ray 이미지 관련 API
- AI 폐렴 예측 API

---

## 4. Git & GitHub Branch 전략 구성

팀원들이 동시에 개발할 수 있도록 **GitHub Flow 방식**으로 협업을 진행하였습니다.

각 기능별로 브랜치를 생성하여 작업하고, 작업이 완료되면 Pull Request를 통해 `main` 브랜치에 병합하였습니다.

```text
main
  ↑
Pull Request
  ↑
feature 브랜치
```

기능별 브랜치를 사용하여 각 팀원의 작업 영역을 분리하고, 작업 내용이 바로 `main` 브랜치에 반영되지 않도록 관리하였습니다.

Pull Request를 통해 변경 내용을 확인한 후 최종적으로 코드를 병합하였습니다.

---

## 5. 프로젝트 세팅

FastAPI를 기반으로 백엔드 프로젝트 환경을 구성하였습니다.

프로젝트의 기능을 관리하기 쉽도록 역할별로 코드를 분리하여 구성하였습니다.

```text
app/
├─ main.py
├─ apis/
├─ schemas/
├─ services/
└─ models/
```

각 영역의 주요 역할은 다음과 같습니다.

- `main.py` : FastAPI 애플리케이션 실행
- `apis` : API Endpoint 관리
- `schemas` : 요청 및 응답 데이터 구조 관리
- `services` : 주요 기능 및 비즈니스 로직 처리
- `models` : 데이터베이스 모델 관리

## 6. API 및 AI 기능 구현

팀원별로 기능을 분담하여 FastAPI 기반 API를 구현하였습니다.

구현한 주요 기능은 다음과 같습니다.

- 로그인 및 사용자 인증
- 회원 조회 및 관리
- 환자 등록 및 조회
- 환자 상세 정보 조회
- 진료 기록 등록 및 조회
- X-Ray 이미지 업로드
- AI 폐렴 예측
- AI 예측 결과 조회

AI 폐렴 예측 기능은 등록된 X-Ray 이미지를 이용하여 다음과 같은 흐름으로 동작하도록 구성하였습니다.

```text
X-Ray 이미지
      ↓
FastAPI
      ↓
AI 예측 모델
      ↓
폐렴 예측
      ↓
예측 결과 반환
```

## 7. 프론트엔드와 API 연동

구현된 FastAPI API를 프론트엔드 화면과 연결하여 실제 서비스 흐름을 테스트하였습니다.

```text
로그인
  ↓
회원 관리
  ↓
환자 관리
  ↓
진료 기록
  ↓
X-Ray 이미지 등록
  ↓
AI 폐렴 예측
  ↓
예측 결과 확인
```

각 기능을 직접 실행하면서 프론트엔드의 요청이 FastAPI로 전달되고 결과가 화면에 정상적으로 표시되는지 확인하였습니다.

이를 통해 사용자 로그인부터 환자 관리, 진료 기록 등록, X-Ray 이미지 업로드, AI 폐렴 예측까지의 기능 연결을 확인하였습니다.

# Alembic Migration Guide

이 프로젝트는 데이터베이스 마이그레이션을 위해 Alembic을 사용합니다.

### 1. 마이그레이션 파일 생성 (자동 생성)

모델(`app/models/`)이 변경된 경우 다음 명령어를 실행하여 마이그레이션 파일을 생성합니다.

```bash
uv run alembic revision --autogenerate -m "변경 내용 설명"
```

### 2. 데이터베이스에 반영

생성된 마이그레이션을 데이터베이스에 적용하려면 다음 명령어를 실행합니다.

```bash
uv run alembic upgrade head
```

### 3. 이전 상태로 되돌리기 (Rollback)

마지막 마이그레이션을 취소하려면 다음 명령어를 실행합니다.

```bash
uv run alembic downgrade -1
```
